**Eye Clinic Management System - Installation & Deployment Guide**

| البند | المواصفة المدعومة |

| **نظام التشغيل** | Windows 7 SP1 (مع Service Pack 1) وحتى Windows 10 و Windows 11 (32-bit & 64-bit) |

## 2. متطلبات ما قبل التثبيت (Prerequisites)

1. **تثبيت حزمة .NET Framework 4.8:**
   - إن لم تكن مثبتة، يتم تثبيت ملف `NDP48-x86-x64-AllOS-ENU.exe` (الرسمي من مايكروسوفت لنظام ويندوز 7 SP1 فما فوق).
2. **تثبيت SQL Server 2014 Express:**
   - يتم تثبيته على **جهاز السيرفر فقط** (جهاز الاستقبال / السكرتارية).
   - أثناء التثبيت، اختر `Mixed Mode Authentication` (مصادقة ويندوز + مصادقة SQL Server).
   - تأكد من تعيين كلمة مرور قوية لمستخدم `sa`.

## 3. خطوات إعداد جهاز السيرفر (جهاز الاستقبال الرئيسي)

### الخطوة 1: ضبط عنوان IP ثابت لجهاز السيرفر (Static IP)
- من لوحة التحكم `Network and Sharing Center` -> اضغط على اتصال الشبكة `Local Area Connection` -> خصائص `Properties`.
- اختر `Internet Protocol Version 4 (TCP/IPv4)` ثم اضغط `Properties`.
- عيّن عنوان IP ثابت، مثال:
  - **IP Address:** `192.168.1.100`
  - **Subnet Mask:** `255.255.255.0`
  - **Default Gateway:** `192.168.1.1`

### الخطوة 2: تفعيل بروتوكول TCP/IP في SQL Server
1. افتح **SQL Server 2014 Configuration Manager**.
2. توجّه إلى `SQL Server Network Configuration` -> ثم `Protocols for SQLEXPRESS`.
3. اضغط بالزر الأيمن على `TCP/IP` واختر **Enable**.
4. افتح خصائص `TCP/IP` -> انتقل إلى تبويب `IP Addresses`.
5. انزل إلى قسم `IPAll`:
   - امسح أي قيمة في `TCP Dynamic Ports`.
   - عيّن `TCP Port` إلى القيمة: `1433`.
6. أعد تشغيل خدمة `SQL Server (SQLEXPRESS)` من قائمة `SQL Server Services`.

### الخطوة 3: فتح المنفذ 1433 في جدار حماية ويندوز (Windows Firewall)
1. افتح `Windows Firewall with Advanced Security`.
2. اضغط على `Inbound Rules` ثم `New Rule...`.
3. اختر نوع القاعدة `Port` ثم `Next`.
4. اختر `TCP` وحدد `Specific local ports: 1433`.
5. اختر `Allow the connection` ثم `Next`.
6. امنح القاعدة اسماً: `SQL Server Port 1433` واضغط `Finish`.

### الخطوة 4: تثبيت تطبيق العيادة
- قم بتشغيل برنامج التثبيت `EyeClinic_Setup_v1.0.0.exe`.
- اختر نوع التثبيت: **تثبيت السيرفر والاستقبال**.
- عند انتهاء التثبيت، سيقوم البرنامج تلقائياً بتهيئة قاعدة البيانات `EyeClinicDb` وجداولها عند أول تشغيل.

## 4. خطوات إعداد جهاز الطبيب (العميل - Client)

1. تأكد من تثبيت .NET Framework 4.8 على جهاز الطبيب.
2. قم بتشغيل برنامج التثبيت `EyeClinic_Setup_v1.0.0.exe` واختر: **تثبيت جهاز الطبيب**.
3. عند تشغيل البرنامج لأول مرة، ستظهر شاشة **إعداد الاتصال بالسيرفر**:
   - **اسم السيرفر أو عنوان IP:** أدخل عنوان جهاز السيرفر (مثال: `192.168.1.100` أو `192.168.1.100\SQLEXPRESS`).
   - **اسم قاعدة البيانات:** `EyeClinicDb`.
   - **رقم المنفذ:** `1433`.
   - **نوع المصادقة:** اختر اسم المستخدم وكلمة المرور الخاصة بقاعدة البيانات أو مصادقة ويندوز.
   - اضغط على **اختبار الاتصال**؛ وعند ظهور "تم الاتصال بنجاح!" اضغط **حفظ ومتابعة**.

## 5. بيانات تسجيل الدخول الافتراضية

| الدور | اسم المستخدم | كلمة المرور الافتراضية | الصلاحيات والمهام |
|---|---|---|---|
| **الطبيب / المدير** | `admin` | `admin123` | كشف كامل، كتابة الروشتة وطباعتها، مراجعة الحسابات، النسخ والاسترجاع، استيراد المرضى، إدارة المستخدمين |
| **السكرتارية** | `secretary` | `sec123` | تسجيل المرضى، حجز الأدوار، تحصيل الرسوم وإصدار الإيصالات، الإقفال اليومي (دون رؤية البيانات الطبية) |

> **ملاحظة أمنية:** يُلزم النظام كلاً من الطبيب والسكرتيرة بتغيير كلمة المرور الافتراضية فور تسجيل الدخول لأول مرة.

## 6. استيراد المرضى من ملفات Excel / CSV

- متوفر لحساب الطبيب فقط عبر زر **📥 استيراد Excel/CSV** في شاشة سجل المرضى.
- يدعم البرنامج قراءة ملفات `.csv` المحفوظة من Microsoft Excel بتشفير UTF-8.
- يمكن أن يتضمن الملف الأعمدة التالية بأسمائها العربية أو الإنجليزية:
  - `الاسم` (إجباري)
  - `الموبايل` (إجباري)
  - `الرقم القومي` (اختياري)
  - `النوع` (ذكر / أنثى)
  - `السن` أو `تاريخ الميلاد`
  - `العنوان`
  - `أمراض مزمنة`
  - `حساسية أدوية`
  - `عمليات سابقة`
  - `ملاحظات`
- يقوم البرنامج بفحص الملف لحظياً وعرض جدول معاينة ملون:
  - **الأخضر (جاهز):** بيانات سليمة ومستعدة للاستيراد.
  - **الأصفر (مكرر):** رقم الهاتف مسجل بالفعل في النظام (مع إمكانية تخطيه تلقائياً).
  - **الأحمر (خطأ):** بيانات ناقصة (كغياب الاسم أو الهاتف)، مع إمكانية تصدير تقرير أخطاء إلى Excel لتصحيحها.

## 7. النسخ الاحتياطي وحماية البيانات

1. **النسخ اليومي التلقائي:**
   - يتيح البرنامج أخذ نسخة احتياطية يومية فورية بنقرة زر واحدة من شاشة الإعدادات.
   - يقوم النظام بتدوير النسخ تلقائياً والاحتفاظ بآخر **30 نسخة** فقط لتوفير مساحة التخزين.
2. **التنبيه الأسبوعي للفلاشة USB:**
   - يُنبّه البرنامج المستخدم أسبوعياً بضرورة توصيل فلاشة خارجية وأخذ نسخة أسبوعية تحسباً لأي طارئ.
3. **استرجاع النسخ الاحتياطية:**
   - محمي بصلاحية الطبيب فقط (`admin`) مع تأكيد أمني مزدوج.

## 9. إجراءات الطوارئ واسترداد حساب الطبيب (Emergency Recovery Procedures)

تم تصميم النظام ليعمل بنمط أمان محلي كامل (**100% Offline Air-Gapped**) دون أي اعتماد على الإنترنت أو البريد الإلكتروني أو الرسائل النصية، لحماية خصوصية بيانات المرضى ومنع أي محاولة استغلال أو اختراق لحساب الطبيب.

### الحالة الأولى: استرداد الطبيب لحسابه ذاتياً بواسطة مفتاح الطوارئ (Master Recovery Key)
1. **توليد المفتاح لأول مرة:**
   - عند أول تشغيل للنظام أو أول دخول للطبيب، يقوم البرنامج تلقائياً بتوليد **مفتاح استرداد رئيسي عشوائي مشفر** مكون من 24 رمزاً (مثال: `9F4K-7M2P-X8A3-B5W9-Q1R6-T4H7`).
   - تظهر نافذة تأكيد أمني إجبارية تُعرض **مرة واحدة فقط**.
   - يقوم الطبيب بالضغط على **🖨 طباعة الوثيقة** لطباعة وثيقة الطوارئ الرسمية أو **💾 حفظ كملف نصي** على فلاشة USB خارجية، ثم وضعها في مكان آمن/خزينة خارج الكمبيوتر.
   - يؤكد الطبيب الإقرار بوضع علامة الصح ثم الضغط على متابعة. يتم تشفير المفتاح وخزن الهاش فقط بالملح داخل قاعدة البيانات.
2. **خطوات الاسترداد عند نسيان الباسورد:**
   - من شاشة تسجيل الدخول الرئيسية، يضغط الطبيب على الزر: **🔑 استرداد كلمة المرور بمفتاح الطوارئ**.
   - يُدخل الطبيب مفتاح الاسترداد المدون في الوثيقة الورقية.
   - يُدخل كلمة المرور الجديدة وتأكيدها (لا تقل عن 6 خانات).
   - عند التحقق، يقوم النظام فوراً بفك قفل الحساب وتحديث كلمة المرور، وتوليد مفتاح استرداد بديل يطبعه الطبيب مجدداً.
   - يتم توثيق عملية الاسترداد تلقائياً في **سجل المراجعة والعمليات (Audit Log)** بالتاريخ والوقت.

---

### الحالة الثانية: إجراء الطوارئ الفني عند ضياع المفتاح والباسورد معاً (Technician DB Reset)
إذا فُقدت كلمة المرور والوثيقة الورقية معاً، لا يمكن لأي مستخدم عادي استرداد الحساب. في هذه الحالة يتدخل المبرمج / الفني المختص حصراً من مستوى قاعدة البيانات وفق الضوابط التالية:

1. **شروط وضوابط الأمان:**
   - **الوصول المادي المباشر (Physical Access):** التواجد الفعلي على جهاز السيرفر بالعيادة؛ يُمنع تنفيذ الإجراء عن بُعد دون إثبات الهوية.
   - **إثبات ملكية الجهاز:** يتضمن السكريبت فحصاً لاسم العيادة المسجل في القاعدة (`Clinic_Name`) وإجمالي عدد ملفات المرضى وتاريخ الإنشاء للتأكد من أن هذا الجهاز يخص العيادة المعنية.
2. **طريقة التنفيذ:**
   - فتح برنامج **SQL Server Management Studio (SSMS)** على جهاز السيرفر.
   - فتح وتشغيل السكريبت الفني المرفق:
     `installer/emergency_reset_doctor_password.sql`
   - يقوم السكريبت بـ:
     - فحص وعرض بيانات العيادة وهاتفها وعدد المرضى للتأكيد.
     - إعادة تعيين كلمة مرور مستخدم الطبيب (`admin`) إلى كلمة مؤقتة: `admin123`.
     - تفعيل خاصية `MustChangePassword = 1` لإجبار الطبيب على تعيين كلمة مرور جديدة خاصة به فور أول تسجيل دخول.
     - إلغاء أي قفل مؤقت وتصفير محاولات الدخول الخاطئة.
     - إعادة ضبط مفتاح الاسترداد (`Doctor_RecoveryKey_HasSeen = 'False'`) ليقوم البرنامج عند أول دخول بتوليد وطباعة مفتاح استرداد ورقي جديد للطبيب.
     - توثيق تدخل الفني تلقائياً في جدول `AuditLog` برقم العملية وتاريخها.
